USE CASE 02

Epidemiology knowledge assistant

Retrieve current, cited guidance from trusted epidemiology sources without replacing professional judgment or official case determination.

Matched code accelerator.NET Virtual Citizen AssistantOpen GitHub repository

Business need

Make trusted guidance easier to use.

Epidemiologists work across changing case definitions, investigation procedures, reporting requirements, code sets, and technical guidance. Finding the right version and the exact supporting passage can take longer than the question itself.

A retrieval-based assistant searches only approved collections, returns the relevant source passages, and makes uncertainty visible. Staff remain responsible for interpreting the evidence and making official epidemiologic decisions.

  • Less time searching across folders, portals, and manuals
  • Answers grounded in visible, versioned source material
  • Faster onboarding and more consistent procedural support

Data involved

Curate the knowledge base as a product.

Authoritative content

Case definitions, surveillance manuals, standard operating procedures, investigation guides, advisories, and approved program FAQs.

Reference data

Condition and laboratory code sets, value-set definitions, reporting thresholds, jurisdiction mappings, and escalation contacts.

Knowledge metadata

Owner, approval status, effective date, superseded date, jurisdiction, program, audience, sensitivity, and source URL.

Operating process

Answer with evidence, not memory.

01

Curate

Approve content, assign owners, and remove superseded versions from active retrieval.

02

Index

Segment documents and retain metadata, permissions, and source location.

03

Retrieve

Use semantic, keyword, or hybrid search to find relevant source passages.

04

Respond

Generate a concise answer with citations, effective dates, and uncertainty.

05

Improve

Review unanswered queries, feedback, content gaps, and retrieval quality.

Applied scenarios

Questions the pattern can support.

SCENARIO 01

Case classification support

An epidemiologist retrieves current measles criteria and the exact source passages before making the official classification.

SCENARIO 02

Investigation workflow

A new investigator asks which interviews, specimens, and follow-up actions are required for a condition in the jurisdiction.

SCENARIO 03

Code-set lookup

An informatician finds the approved mapping between laboratory terminology, reportable-condition logic, and surveillance fields.

Implementation guardrails

Make authority and currency explicit.

1

Approved sources only

Separate draft or informal material from content authorized for operational use.

2

Citations by default

Every answer should expose source title, passage, owner, and effective date.

3

Role-aware access

Enforce source permissions before retrieval, not only when displaying the answer.

4

No autonomous decisions

Do not allow the assistant to finalize case status, clinical action, or enforcement decisions.

Adapt the cited-search pattern.

The .NET accelerator includes chat, semantic and hybrid document search, citations, category browsing, and a data-upload utility. Replace citizen-service content with curated epidemiology knowledge.
