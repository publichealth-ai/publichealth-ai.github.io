USE CASE 03 · COMMUNITY SERVICES

Public inquiry response assistant

Help contact-center and program staff prepare consistent answers from approved public health content, with citations and clear escalation.

Related Azure AI App TemplateAzure Language OpenAI Conversational Agent Accelerator

Combines conversational understanding and question answering with an Azure OpenAI RAG experience.

View template

Business need

Hotlines and program offices need fast, current answers while recognizing questions that require clinical, urgent, or program escalation. The assistant drafts; staff remain in control.

Data involved

Approved FAQs, advisories, response scripts, referral directories, clinic information, translations, escalation rules, content dates, and de-identified interaction metrics.

01Receive

Capture a question from an approved channel.

02Understand

Identify topic, urgency, and language.

03Retrieve

Find the current approved response.

04Review

Staff verify, edit, or escalate the draft.

05Improve

Use unresolved questions to close gaps.

Applied scenarios

  • Draft a cited response about where a resident can obtain a vaccine.
  • Detect a potentially urgent exposure question and route it to staff.
  • Provide current intake and jurisdiction guidance for an environmental complaint.

Required guardrails

  • Assign an owner and review date to every answer source.
  • Define explicit urgent and clinical escalation.
  • Use qualified human review for translated content.
  • Collect only the personal data required for the service.
