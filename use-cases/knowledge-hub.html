USE CASE 06 · SURVEILLANCE & INFORMATICS

Cross-agency surveillance knowledge hub

Search partner guidance across organizational boundaries without bypassing the permissions attached to each source.

Related Azure AI App TemplateAI application with SharePoint knowledge and actions

Uses SharePoint semantic retrieval and its built-in access controls for grounded agent responses.

View template

Business need

Surveillance knowledge spans health departments, laboratories, healthcare partners, emergency management, and environmental programs. Staff need unified discovery while source owners retain control.

Data involved

Reporting protocols, laboratory guidance, plans, technical standards, identity and security groups, source permissions, sensitivity, document versions, citations, and access audit records.

01Authenticate

Verify identity, role, and agency.

02Authorize

Define the permitted search scope.

03Retrieve

Search only authorized sources.

04Synthesize

Preserve citations and ownership.

05Audit

Record access and route exceptions.

Applied scenarios

  • Find current state and local reporting requirements with each source identified.
  • Retrieve related laboratory and environmental procedures across partners.
  • Search emergency plans while each agency retains its original records.

Required guardrails

  • Apply security before retrieval, not after generation.
  • Keep source owners responsible for permissions and currency.
  • Test that users cannot infer restricted content.
  • Align access logs with approved retention policy.
