USE CASE 06

Cross-agency surveillance knowledge hub

Search partner guidance and program knowledge across organizational boundaries without bypassing the permissions attached to each source.

Matched code acceleratorInter-Agency Knowledge HubOpen GitHub repository

Business need

Connect knowledge without flattening access.

Surveillance work depends on information held across health departments, laboratories, healthcare partners, emergency management, environmental programs, and other agencies. Staff need a unified way to find related guidance while source owners retain control of restricted content.

A permission-aware hub authenticates the user first, applies source-level access before search, returns cited results from only authorized collections, and records the query and source access. It supports discovery and synthesis without creating a new unrestricted copy of every document.

  • Faster discovery across authorized partner collections
  • Consistent citation and source ownership across results
  • Auditable access that respects existing organizational boundaries

Data involved

Treat permissions as part of the data.

Partner knowledge

Reporting protocols, laboratory guidance, health alerts, jurisdiction procedures, emergency plans, technical standards, and program documentation.

Identity and access

User identity, agency and role, security groups, source permissions, data-use terms, sensitivity, and expiration or revocation status.

Audit and provenance

Query, filters, source collection, document version, citations returned, access decision, user feedback, and escalation history.

Operating process

Authorize before retrieval.

01

Authenticate

Verify user identity, role, agency, and current access groups.

02

Authorize

Determine which source collections and documents the user may search.

03

Retrieve

Run hybrid search only across the authorized search scope.

04

Synthesize

Return a cited answer that preserves agency, owner, and source distinctions.

05

Audit

Record access and route unresolved or restricted requests to source owners.

Applied scenarios

Cross-boundary questions the hub can support.

SCENARIO 01

Reporting requirements

An informatician finds current state and local requirements across authorized repositories with each jurisdiction clearly cited.

SCENARIO 02

Partner investigation

An epidemiologist retrieves related laboratory and environmental procedures without gaining access to unrelated restricted content.

SCENARIO 03

Emergency coordination

Authorized response staff search relevant plans and agreements while each partner retains ownership of the original records.

Implementation guardrails

Make access decisions testable.

1

Pre-retrieval security

Never retrieve restricted content and attempt to hide it after generation.

2

Source ownership

Keep content owners responsible for permissions, currency, retention, and correction.

3

Boundary testing

Continuously test that users cannot infer or retrieve content outside authorized scope.

4

Durable audit

Align query and access logs with policy, investigation needs, and approved retention periods.
