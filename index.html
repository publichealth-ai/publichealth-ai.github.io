01

Case and laboratory document intake

Reduce manual entry by classifying incoming reports, extracting surveillance fields, and routing uncertain values for validation.

Replicate code ↗

Data

Case-report forms, laboratory PDFs, scanned faxes, demographics, dates, diagnoses, and test results.

Process

Ingest → classify → extract → score confidence → human validate → load

Scenario

A scanned disease report arrives by fax; key fields are drafted for an epidemiologist before entry into the surveillance system.

02

Epidemiology knowledge assistant

Help staff find cited answers across case definitions, investigation protocols, code sets, and program guidance.

Replicate code ↗

Data

Case definitions, standard operating procedures, investigation guides, code sets, FAQs, and training materials.

Process

Index documents → retrieve evidence → generate cited answer → review or escalate

Scenario

An epidemiologist retrieves the current measles classification criteria and source passages before making the case determination.

03

Public inquiry response assistant

Give contact-center and program staff fast, consistent, citation-backed drafts for common public health questions.

Replicate code ↗

Data

Approved FAQs, advisories, program guidance, referral directories, translations, and escalation rules.

Process

Receive question → retrieve approved content → cite and score → staff review or escalate

Scenario

A hotline specialist receives a cited draft explaining where and when a resident can obtain a recommended vaccine.

04

Public health service navigator

Provide resident self-service across clinics, testing, vaccination, alerts, and other local health services.

Replicate code ↗

Data

Service directories, locations, hours, eligibility guidance, appointment APIs, and current public health alerts.

Process

Understand intent → retrieve guidance → call service plugin → respond → hand off

Scenario

A resident asks in plain language for a nearby testing site and receives current hours, directions, and next steps.

05

Public health emergency coordination

Develop a shared operational picture and draft coordinated plans across surveillance, clinical, logistics, and partner teams.

Replicate code ↗

Data

Surveillance summaries, hospital capacity, staffing and supplies, weather, maps, partner status, and prior after-action reports.

Process

Define event → run specialist assessments → assemble plan → command review → update

Scenario

During a heat emergency, teams combine health signals, weather forecasts, cooling-center capacity, and outreach resources.

06

Cross-agency surveillance knowledge hub

Search partner guidance and program knowledge while enforcing the permissions attached to each source.

Replicate code ↗

Data

Agency guidance, reporting protocols, data-use agreements, partner documents, access groups, and audit records.

Process

Authenticate → filter by permission → hybrid search → cite sources → audit access

Scenario

An informatician finds state and local reporting requirements across authorized repositories without exposing restricted content.

07

Surveillance policy and protocol review

Identify missing or inconsistent requirements in draft protocols before formal privacy, security, legal, and program review.

Replicate code ↗

Data

Draft protocols, data-use agreements, retention schedules, policy rules, security controls, and accessibility standards.

Process

Parse document → apply rules and analysis → rank findings → owner review → revise

Scenario

A new syndromic surveillance procedure is checked for retention, access, audit, and approval language before submission.

Implementation note: These accelerators are adaptation starting points. Any use involving protected health information or operational decisions requires agency privacy, security, legal, accessibility, records, and human-oversight controls.
